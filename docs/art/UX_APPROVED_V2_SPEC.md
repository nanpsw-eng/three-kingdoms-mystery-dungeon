# Approved ink UX v2 — 2026-10-08

Status: USER_APPROVED_IMPLEMENTATION. 기존 DEC-025 수묵 그래픽 노블 방향의 UI delta.

## 승인 / 범위

사용자가 적대적 UX 검토 후 ① 핵심3화면 시안을 요청하고, 수정 시안에 대해 ① 탐험→전투→첫 화면 구현을 승인했다. 이번 구현은 main 병합/운영 배포 승인과 구분한다.

- 탐험: 자동 탐색→자동 이동, 주변 탐색→함정 찾기, 조사→사물 조사. 조건/턴 비용은 기존 Domain에 맞춘다.
- 목표 안내, 청록/주홍/황토 지도 범례, 일반 행동/보조 메뉴의 한지 표면. 상태/도움말/지도 안내는 더보기에서 접근한다.
- 전투: 행동자 청록, 선택 대상 주홍+대상 문구. 앞3+뒤2 그대로. 일반 공격과 단일/다중 기술·물품도 대상 선택→실행, 취소/Escape는 무료. 자신 대상 기술은 자신을 미리 선택하되 실행 전 대기.
- 자동 방식4종/속도3종을 설정 패널로 묶는다. 패널을 열면 기존 자동 timer가 멈추고 닫으면 재개. 진행 중 수동 전환은 바로 접근 가능.
- 첫 화면: 저장 원정이 있으면 이어하기 중심. 새 원정 편성은 별도 상태. 탐색/돌아가기/대체 확인 취소는 기존 save를 보존. 원정 시작 확정 시에만 교체.
- 캠페인 연표는 접힌 details. 신규 사용자는 군주→장수2명→원정 시작 순서. 해금된 군주만 선택 가능하며 미해금 정보는 도감에서 제공.
- 다음 목표는 실제 ContentPack.unlocks의 해당 캠페인 reach-depth 조건만 사용. 해금은 원정 종료 후 반영. 생성 시안의 상자/카드 보상 그림을 도입하지 않는다.

## 구현 기준

원본 그림을 게임 화면 전체 스크린샷으로 사용하지 않는다. 기존 인물/한지/먹 자산을 재사용하고 텍스트/버튼은 DOM으로 유지한다. 생성 시안은 방향 참고이며 픽셀 동일 재현 계약이 아니다. Domain/seed/RNG/save v1/전투 밸런스를 변경하지 않는다.

320×568~844×390에서 탐험 지도 최소180px, 조작 최소44px, viewport overflow 없음. 작은 세로 화면은 Lv/턴을 상태 메뉴에서 확인하고, 파티 초상은 최소30×32px로 조정한다. 전투 field 내부 스크롤은 기존 규칙대로 허용하되 명령/확인/취소는 화면 안에 유지한다.
