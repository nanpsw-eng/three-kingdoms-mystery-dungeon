# 필드 수묵 미니어처 — 승인 방향과 자산 계약

2026-10-08 KST 사용자 선택 **② 수묵 미니어처**. DEC-025/Visual Bible의 한지·먹·제한 색상을 유지하면서 필드용 자산을 새로 제작한다. 운영 배포 보류는 유지한다.

## 표시

- 군주: 유비·조조·손권 각 미니어처. 영입 표식은 공통 무장 미니어처.
- 적: 황건 창/궁, 일반 창/궁, 기병, 술사, 중갑, 지휘관, 남방 전사/궁 역할별 공유 자산. 필드의 적 표식은 부대 하나를 대표하며 전투 인물 초상과 구분한다.
- 아군 청록 원형+깃발, 적 주홍 원형+삼각 깃발, 보스 이중 깃발, 물품 황토 원형+마름모. 색 이외에 모양으로 구분한다.
- 물품: 군량·약·약초·두루마리·상자·검·창·활·부채·갑옷·보물. 현재 콘텐츠 아이템/장비 전체를 렌더링 계층에서 매핑한다. 보상/아이템 ID는 변경하지 않는다.
- 계단·문·노출 함정도 같은 먹선과 절제된 명암으로 표시한다.
- 바닥 원본 재료는 22% 농도로 한지색 위에 합성, 칸 경계는 얇게 표시. 벽은 어두운 먹톤으로 정리. 안개·바닥 특수 조건의 의미는 유지한다.
- 기본 확대 11×11, 넓게 15×15. 중심은 군주이며 터치 좌표는 선택 배율을 따른다. 배율 변경은 턴/저장 명령을 변경하지 않는다.

## 제작 / 재현 지침

내장 imagegen으로 두 투명 시트를 생성했다. 승인된 ② 시안과 기존 Visual Bible를 스타일 기준으로 사용했다. 한지 배경이 없는 투명 윤곽, 강한 검은 먹선, 상아색 하이라이트, 저채도 청록·주홍·황토, 약 3등신 성인 비율, 3/4 정면, 28px에서도 읽을 수 있는 무기/물품 실루엣. 글자·깃발·바닥 원형은 이미지에 넣지 않고 렌더러가 표시한다.

- `web/assets/field/ink-miniatures-v1.webp`: 1536×1024, 6열×4행, 24종. 행 source band는 실측 `[0,280,565,790,1024]`. 투명 alpha 경계를 읽어 각 sprite의 실물을 한 칸 안에 맞춘다.
- `web/assets/field/ink-regular-miniatures-v1.webp`: 1254×1254, 일반 병사/남방 전사 4종 추가 시트. 아래 행 column boundary는 원본 폭의 55%에서 분리해 긴 창끝을 보존한다. 황건 두건을 다른 세력에 사용하지 않는다.
- PNG→lossless WebP 인코딩은 모든 alpha와 alpha>0 픽셀의 RGBA 동일성을 확인한다. 원본 의미/색상/윤곽을 수정하지 않고 전송 크기를 줄인다.
- 요술진은 적을 강화하는 별도 주홍 원형 인장으로 표시하며 물품 표시와 구분한다. 기존 인물 초상·전투 그림·도감 자산은 교체하지 않는다. 필드 시트 누락 시 기존 token/procedural renderer로 돌아가며 구분 표식은 유지한다.

`web/src/field-art.ts`는 표시용 source/역할/물품 매핑만 소유한다. Domain/RNG/세이브/밸런스에는 접근하지 않는다.
