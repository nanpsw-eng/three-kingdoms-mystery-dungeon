# 나머지 그래픽 시안 적용 조사 — 2026-10-07

## 결론

**전체 시안 적용 완료가 아니다.** 초상·전신, 한지/먹선 테마, 후기 아이템 SVG 실루엣은 게임에 연결돼 있다. 그러나 탐험용 전신 토큰, 상세 던전 오브젝트 삽화, 도감 보조 탭의 그림, 스토리 장면 배경은 미반영 또는 부분 반영이다. 기존 자산 개수와 디코딩 통과는 시안 충실도 판정과 별개다.

조사 기준: main `7d022234e28178a24b067c0b3b9ac7a9d5d26d97`; Vercel 운영 `dpl_CghLvLMFxRvmWWvWGVthMbc7Moz1` READY, 동일 SHA 확인. exact AI-OS v0.4.4 Binding, AGENTS, DEC-025, Visual Bible, 누적 시안 사양과 현재 renderer를 적용했다. 이번 세션은 조사·문서 기록이며 게임 코드와 자산을 변경하지 않았다.

- 읽을 수 있는 래스터 전체를 비교 보드로 육안 검토하고 실제 production 초상·전신·토큰 및 atlas와 대조했다. 시안 파일마다 조사 그룹·판정·체크섬을 JSON에 기록했다.
- `assets.ts`, `main.ts`, `map.ts`, `sprites.ts`, `codex.ts`, `story.ts`, `style.css`, manifest와 생성 스크립트에서 실제 사용 경로를 추적했다.
- PR #17 최종 visual CI `37620211206`의 실제 title/battle/party/codex 캡처를 검토했다. 같은 게임 코드가 현재 운영에 배포돼 있다. 새 플레이 세션·후반 전역 전체·실물 단말 재검증은 NOT_RUN이다.
- SVG 비교는 시안 검토용 바닥 `<use href="#floor">`만 제외하고 fog filter ID 이름을 정규화했다. 도형/색/선 속성은 그대로 비교했다. 단순 파일명·개수만으로 판정하지 않았다.

## 우선순위 제안

1. 군주 탐험 토큰 v2를 실제 지도에 연결하고 작은 칸·배경·전투 순서칩에서 검증. 초상/전신/토큰이 같은 인물이라는 핵심 미반영 사항이다.
2. 도감 보스 초상·물품 아이콘·업적 시각 표시 연결. 이미 존재하는 자산과 현재 데이터로 구현 가능하며 새 게임 규칙은 필요 없다.
3. 상세 던전 오브젝트 원화와 후기 SVG 중 적용 목표를 항목별로 명시하고 필요한 원화만 연결. 상자·저장 항아리는 렌더러 교체만으로 활성화할 수 없는 게임 모델 차이를 먼저 기록한다.
4. 스토리 배경과 남은 효과는 모바일 가독성/크기와 현재 scene/상태 계약을 유지하며 구현. 기준 이미지 1개 복구 병행.

최신 작업 요청은 적용 여부 조사다. 위 제안은 조사 결과이며 이번 세션에서 runtime 구현 또는 배포 완료로 표시하지 않았다.
