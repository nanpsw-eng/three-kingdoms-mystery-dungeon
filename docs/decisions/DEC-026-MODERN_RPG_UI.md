# DEC-026 — 현대 2D RPG 개편과 작은 방

2026-10-09. 사용자는 수묵 스타일과 기존 UI 전체 교체를 허용하고 현대 2D RPG 방향 및 실제 구현을 선택했다. 큰 방 축소 검토 후 “계속 개선해” 지시를 compact-v2 구현 승인으로 기록한다. 2026-10-10 사용자 ① 정식 배포 진행 승인으로 main merge/운영 배포 승인 완료. PR25 병합 및 운영 READY.

DEC-025 시각 방향을 현대 컬러 만화 RPG로 대체한다. 지도·전투·얼굴을 동일 전신 atlas로 통일한다. 고유 주요 인물7+공용 역할9이며 모든48인 고유 신규 그림을 의미하지 않는다. 이야기 삽화와 실패 fallback은 유지한다.

기본 화면9×9, 넓게15×15. 8방향 입력은 놓을 때1칸 실행하고 중앙/바깥/취소 이벤트는 무료다. 대기는 별도다. 대상 먼저 선택→공격, 기술 비용/효과 설명, 내부 스크롤 도감/가방을 적용한다. 앞3/뒤2와 전투 규칙·수치는 유지한다.

DEC-012/013의 방+복도, 방5~9개, 방 시야, 행동 턴 규칙을 유지한다. 새 웹 원정의 방만4~6×4~6으로 축소한다. 층48×34는 유지하며40×28 및 특별 대형 보스방은 후속 후보다. 기존 옵션/저장은 legacy-v1로 재생하고 새 옵션만compact-v2를 명시한다. 전체 층 전환에도 생성 버전을 전달한다.

새 compact 저장 생성 후 구형 운영88becf5 전체 artifact로 복귀하면 신규 기록 재생이 호환되지 않는다. 복구는 버전별 생성기를 보존한 수정 릴리스로 진행하며 세이브 초기화를 사용하지 않는다. 기존 저장을 일괄 변환하지 않는다.

검증과 제한은 [완료 보고서](../reports/MODERN_RPG_V1_20261009.md), 구현 계약은 [명세](../art/MODERN_RPG_V1_SPEC.md). 난이도 동일성을 보증하지 않으며 실제 플레이 후 후속 조정을 결정한다.
