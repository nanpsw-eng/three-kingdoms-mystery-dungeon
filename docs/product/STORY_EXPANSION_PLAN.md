## 1. 기본 방향

| 항목 | 권장안 | 근거 |
|---|---|---|
| 구조 | **전역 단위 독립 런**(전역 1개 = 12~15층 = 20~30분), 연표 순서로 해금 | 현 Run 구조·밸런스·시뮬레이션 그대로 재사용, 모바일 세션 길이 유지 |
| 서사 | **연의 기준**(관우 천리행, 칠종칠금, 화살 십만 개 등) + 정사 주석은 도감에 | 던전·전투 기믹으로 바꾸기 좋은 극적 사건이 연의에 집중 |
| 시점 | 1차는 **공통 역사 시점**, 군주별 차이는 대사·이벤트·보너스로만 | 위·촉·오 분기 루트는 콘텐츠 3배 → 2차 검토 |
| 영구 성장 | 기존 원칙 유지(DEC-002·016): 해금만 영구 | 볼륨이 늘어도 수치 인플레이션 금지 |

## 3. 로스터 확장 (현재 15명 → 약 50명)

해금 방식: 전역 클리어·특정 보스 격파·**적장 등용**(격파한 이름 있는 장수를 일정 확률로 영입 → 이후 영구 해금).

| 전역 | 신규 플레이어블 후보 |
|---|---|
| E2 | 여포, 손견, 원소, 조인, 화웅(등용) |
| E3 | 진궁, 장패, 고순, 미축 |
| E4 | 허저, 전위, 순욱, 안량, 문추 |
| E5 | 노숙, 황개, 방통, 정보 |
| E6 | 마초, 위연, 법정, 서황, 하후연 |
| E7 | 육손, 여몽, 주태 |
| E8 | 맹획, 축융, 강유 |
| E9 | 사마의(최종 해금 군주 후보), 장합, 등애 |

군주는 유비·조조·손권 3명 유지 + 최종 해금 군주 1명(사마의) 검토.
