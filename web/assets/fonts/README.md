# Local font assets

Existing UI fonts are bundled locally so Korean text does not depend on a third-party request.
WOFF2 conversion preserves the font glyphs; no subset or design modification was made.

- Gowun Dodum Regular: https://github.com/google/fonts/tree/main/ofl/gowundodum
- Gowun Batang Regular/Bold: https://github.com/google/fonts/tree/main/ofl/gowunbatang
- Downloaded 2026-10-06; copyright and SIL Open Font License 1.1 are preserved in the adjacent OFL files.
